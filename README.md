# C-Ourse

C-Ourse is a hands-on journey through the C programming language. The goal is
to understand C by writing programs from scratch, studying how they work, and
learning from the mistakes we make along the way.

## Handmade code

All course code is written by hand, without using an LLM to generate it. This
is intentional: learning C means developing the ability to reason about every
line, understand memory, debug problems, and build solutions independently.

LLMs may be used only to help write documentation, improve explanations, and
describe code that has already been written. They are not used to produce the
course's C code.

## What we will learn

The course begins with the fundamentals of C and gradually moves into
intermediate topics. Along the way, we will explore:

- C syntax, types, control flow, and functions
- Pointers, arrays, strings, and memory management
- Data structures and larger multi-file programs
- Debugging, testing, and safer programming practices
- The design and implementation of a small toy programming language
- Common software vulnerabilities, how insecure code is exploited, and how to
  recognize, prevent, and mitigate those weaknesses

Security-related exercises may include small proof-of-concept programs that
demonstrate techniques such as keystroke capture and dictionary-based password
attacks. These exercises are strictly for educational use in controlled,
authorized environments. Their purpose is to understand how vulnerable
software fails and to learn how to defend systems against these threats.

## Approach

This repository is a learning journal as much as it is a course. The examples
may not always show the shortest or most polished solution. They show the
process of learning C: writing code, breaking it, understanding why it broke,
and improving it.
